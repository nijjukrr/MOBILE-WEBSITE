# Tirrupur Mobile Website

[![Vercel Deployment](https://img.shields.io/badge/Deployed_on-Vercel-black?logo=vercel)](https://tirrupur-mobile.vercel.app)
[![Website Preview](https://img.shields.io/badge/Live_Demo-View_Now-brightgreen)](https://tirrupur-mobile.vercel.app)

Welcome to the **Tirrupur Mobile** project—a modern, sleek, and highly interactive storefront designed to provide a premium digital experience. The site leverages dark-mode aesthetics, neon accents (pink, green, red), and glassmorphism to showcase the latest smartphones and high-end accessories.

## 🚀 Features

- **Interactive Dragon Background**: A futuristic, mouse-following SVG dragon animation runs smoothly in the background, creating a high-tech atmosphere without distracting from the products.
- **Glassmorphism Design**: Frosted glass effects on product and review cards for a modern, sleek appearance.
- **Dynamic Headphone Slider**: An integrated, animated "Apple AirPods Max" accessory showcase featuring color-changing backgrounds that sync perfectly with the sliding product images.
- **Local Video Showcase**: A seamlessly integrated video gallery highlighting the latest mobile tech via ultra-wide and vertical video formats, directly served from local assets.
- **Fully Responsive Layout**: Built with CSS Grid and Flexbox to ensure perfect scaling across all devices—from mobile phones to desktop monitors.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure for accessibility and SEO optimization.
- **CSS3 (Vanilla)**: Custom styling utilizing CSS variables for easy theming, flexbox/grid for layouts, and advanced keyframe animations.
- **JavaScript (Vanilla)**: Handles the interactive dragon logic, the smooth automated accessory slider, and unified smooth scrolling for navigation.

## ⚙️ Getting Started

To view the project locally, simply clone the repository and open the `index.html` file in any modern web browser.

```bash
git clone https://github.com/nijjukrr/MOBILE-WEBSITE.git
cd MOBILE-WEBSITE
# Open index.html in your browser
```

No build tools or heavy frameworks are required.

## 🌐 Deployment

This project is optimized for incredibly fast static deployment. It can be easily hosted on platforms like **Vercel**, **GitHub Pages**, or **Netlify**.
